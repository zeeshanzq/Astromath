🚀 AstroMath Quest

An interactive, gamified mathematics learning web application designed for 8-year-old learners, aligning with Swedish and British primary school math curricula.

✨ Key Features

👤 Student Profiles & Per-Name Progress: Save and switch between student names so each child's XP, Star Coins, streak badges, table mastery stars, and assessment report cards are stored separately in the browser.

🎵 Musical Feedback: Plays an uplifting musical chime/fanfare for correct answers and a calm, encouraging low tone for incorrect attempts, with an easy sound toggle in the header.

🛸 Adventure Quest & Missing Numbers (? + x = y): Progressive difficulty levels (Cadet 1–20, Explorer 1–100, Commander 1–1000) covering addition, subtraction, word problems, and missing-number equations.

💡 Visual Strategy Helper ("Show Me How!"): Dynamic SVG diagrams teaching when and how to apply each method:

Make-10 / Tiokompisar (Number bonds to 10)

Number Line / Tallinje (Step-by-step bridging jumps)

Partitioning (Splitting tens and ones)

Column Method / Uppställning (Vertical place-value alignment)

🧠 Pick the Best Method: A dedicated mini-game focused on recognizing which strategy fits a problem best before calculating.

⚡ Times Tables Dojo (2× – 10×): Select a specific table (such as 2× or 5×) or Mix All, complete with visual dot arrays, skip-counting jumps, memory rules, missing-factor puzzles (2 × ? = 14), a toggleable Study Card, and 3-star mastery tracking.

📋 Mission Checkup (Assessments): 10-question assessments with an optional calm timer, Rocket Medals, a Parent & Explorer Skill Breakdown, and visual strategy review for missed questions.

🚀 How to Run

Option 1: Run Locally (Offline)

Download index.html from this repository.

Double-click index.html to open it in any modern web browser (Chrome, Safari, Edge, or Firefox).


🛠️ Tech Stack

Zero-dependency single-file HTML5, Tailwind CSS (CDN), and Vanilla JavaScript.

Built-in Web Audio API synthesizer for sound effects and music cues (no external audio files required).

Automatic local progress persistence via browser localStorage.
